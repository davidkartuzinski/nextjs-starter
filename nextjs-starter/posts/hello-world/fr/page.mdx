# Bonjour le Monde !

Ceci est mon premier article de blog utilisant **MDX** dans Next.js !

## Qu'est-ce que MDX ?

MDX est un format qui vous permet d'écrire du JSX dans vos documents markdown. Vous pouvez importer des composants, comme des graphiques interactifs ou des notifications, et les intégrer dans votre contenu.

## Exemple de Code

```javascript

  return `Bonjour, ${nom} !`;
}

console.log(salutation('Monde'));
```
