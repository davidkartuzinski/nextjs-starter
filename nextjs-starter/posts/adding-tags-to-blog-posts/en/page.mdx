# Adding Tags to Blog Posts - A Complete Guide

Tags are an essential feature for organizing and categorizing blog content. In this comprehensive guide, we'll walk through every step needed to add tags to your blog posts, including translations, routing, and technical considerations.

- **Tag assignment** in blog post frontmatter

- **Sidebar integration** with post count filtering

## Step 3: Understanding Tag Routing

### URL Structure

Our tag system uses locale-specific routing:

- **English**: `/en/blog/tag/[tag]`
- **Spanish**: `/es/blog/etiqueta/[tag]`
- **French**: `/fr/blog/etiquette/[tag]`

### Route Files

```
src/app/[locale]/(user-routes)/blog/
├── tag/[tag]/page.js          # English tags
├── etiqueta/[tag]/page.js     # Spanish tags
└── etiquette/[tag]/page.js    # French tags
```

### Example URLs

- English: `/en/blog/tag/nextjs`
- Spanish: `/es/blog/etiqueta/nextjs`
- French: `/fr/blog/etiquette/nextjs`

## Step 4: Tag Name to Slug Mapping

### How It Works

The system automatically maps tag names to slugs:

```javascript
// Tag names in posts
tags: ['Next.js', 'Tutorial', 'JavaScript']

// Mapped to slugs
'Next.js' → 'nextjs'
'Tutorial' → 'tutorial'
'JavaScript' → 'javascript'
```

### Mapping Logic

```javascript
const matchingTag = translatedTags.find(
  (t) =>
    t.name === tag ||
    t.name.toLowerCase() === tag.toLowerCase() ||
    t.slug ===
      tag
        .toLowerCase()
        .replace(/[^a-z0-9\s-]/g, '')
        .replace(/\s+/g, '-')
);
```

## Step 5: Tag Widget Integration

### Sidebar Configuration

The TagWidget displays tags with post counts and filters by minimum post count:

```javascript
<TagWidget
  tags={tags}
  locale={locale}
  minPostCount={2} // Show tags with 2+ posts
/>
```

### Post Count Filtering

- `minPostCount={1}`: Show all tags
- `minPostCount={2}`: Show only tags with 2+ posts
- `minPostCount={3}`: Show only tags with 3+ posts

## Step 6: Blog Card Tag Links

### Automatic URL Generation

Blog cards automatically generate clickable tag links:

```javascript
// In BlogPostCard.js
const tagUrls = {};
for (const tag of post.tags) {
  const matchingTag = translatedTags.find((t) => t.name === tag);
  const tagSlug = matchingTag ? matchingTag.slug : tag;
  tagUrls[tag] = await getTagUrl(tagSlug, locale);
}
```

### Display in Cards

```jsx
{
  post.tags?.map((tag) => (
    <Badge key={tag} variant='secondary'>
      <Link href={tagUrls[tag]}>{tagNames[tag] || tag}</Link>
    </Badge>
  ));
}
```

## Important Considerations

- **Use descriptive names**: "Next.js" instead of "next"
- **Be consistent**: Use the same tag name across all locales
- **Avoid special characters**: Stick to letters, numbers, and spaces

### 2. Translation Consistency

- **Keep tag names consistent** across all locale files
- **Update all locales** when adding new tags
- **Use appropriate translations** for descriptions

### 3. URL Structure

- **Slugs are automatically generated** from tag names
- **URLs are locale-specific** with proper routing
- **Fallback handling** for missing translations

### 4. Performance Considerations

- **Tag data is cached** for better performance
- **Post counts are calculated** dynamically
- **URL generation** is optimized with fallbacks

### 5. SEO Benefits

- **Tag pages are SEO-friendly** with proper metadata

## Troubleshooting

### Common Issues

1. **Tags not showing in sidebar**

   - Check `minPostCount` setting
   - Verify tag names match translation files
   - Ensure tags are properly assigned to posts

2. **Tag links not working**

   - Verify tag names in translation files
   - Check slug generation logic
   - Ensure proper URL routing

3. **Missing translations**
   - Add tags to all locale files
   - Use consistent tag names
   - Check fallback handling

### Debug Steps

1. **Check browser console** for errors
2. **Verify tag data** in network requests
3. **Test URL generation** manually
4. **Check translation files** for consistency
