# Comenzando con Next.js

Next.js es un framework de React que habilita funcionalidades como el renderizado del lado del servidor y la generación de sitios estáticos.

## ¿Por qué Next.js?

- **Renderizado del Lado del Servidor**: Mejora el rendimiento y SEO
- **Generación de Sitios Estáticos**: Pre-renderiza páginas en tiempo de construcción
- **Rutas API**: Crea endpoints API como parte de tu aplicación Next.js
- **Enrutamiento Basado en Archivos**: Crea rutas basadas en la estructura de archivos
- **Soporte CSS Integrado**: Usa CSS Modules, Sass y más

## Instalación

```bash
npx create-next-app@latest mi-aplicacion-next
cd mi-aplicacion-next
npm run dev
```

## Enrutamiento Básico

Next.js tiene un enrutador basado en el sistema de archivos construido sobre el concepto de páginas. Cuando se agrega un archivo al directorio `pages`, automáticamente está disponible como una ruta.

## Conclusión

Next.js proporciona una excelente experiencia de desarrollador con todas las características que necesitas para producción.
