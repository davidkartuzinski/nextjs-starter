## Introducción

Tailwind es poderoso, rápido y popular. Pero cuando se combina con **Shadcn UI**, se convierte en **un kit de herramientas imparable** para el desarrollo frontend en Next.js.

---

## Tailwind Solo

Usar Tailwind por sí solo te da:

- CSS utility-first.
- Sistema de diseño completamente personalizable.
- CSS sin runtime.
- Soporte responsive y mobile-first.

Pero **no proporciona componentes UI reales**. Debes construir cada botón, modal y dropdown tú mismo.

---

## Entra Shadcn UI

Shadcn UI proporciona **componentes accesibles y pre-construidos**, impulsados por Radix y estilizados usando Tailwind.

Beneficios:

- ✅ Componible y temable.
- ✅ Usa tu propia configuración de Tailwind.
- ✅ Sin dependencia del proveedor.
- ✅ Soporte fácil para modo oscuro.

---

## Uso en Next.js

Solo ejecuta:

```bash
npx shadcn-ui@latest init
```

Y tu proyecto obtiene:
• Primitivas UI como < Button />, < Dialog />, etc.
• Estilos predeterminados sensatos.
• Una forma limpia de organizar componentes.

## Conclusión

Usa Tailwind solo para máximo control. Agrega Shadcn para UI rápida y accesible que aún respeta tu sistema de diseño.
