## Introduction

Tailwind est puissant, rapide et populaire. Mais quand il est associé à **Shadcn UI**, il devient **une boîte à outils imparable** pour le développement frontend dans Next.js.

---

## Tailwind Seul

Utiliser Tailwind seul vous donne :

- CSS utility-first.
- Système de design entièrement personnalisable.
- CSS sans runtime.
- Support responsive et mobile-first.

Mais il **ne fournit pas de vrais composants UI**. Vous devez construire chaque bouton, modal et dropdown vous-même.

---

## Entre Shadcn UI

Shadcn UI fournit **des composants accessibles et pré-construits**, alimentés par Radix et stylés en utilisant Tailwind.

Avantages :

- ✅ Composable et thémable.
- ✅ Utilise votre propre configuration Tailwind.
- ✅ Pas de verrouillage fournisseur.
- ✅ Support facile du mode sombre.

---

## Utilisation dans Next.js

Il suffit d'exécuter :

```bash
npx shadcn-ui@latest init
```

Et votre projet gagne :
• Des primitives UI comme < Button />, < Dialog />, etc.
• Des styles par défaut sensés.
• Une façon propre d'organiser les composants.

## Conclusion

Utilisez Tailwind seul pour un contrôle maximum. Ajoutez Shadcn pour une UI rapide et accessible qui respecte encore votre système de design.
