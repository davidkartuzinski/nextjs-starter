## Code et Coloration de Syntaxe (avec PrismJS)

Utiliser PrismJS avec Next.js vous donne la capacité de partager et mettre en évidence des extraits de code.

```
Le code en ligne n'a qu'une `accent grave` autour.
```

Exemple de Code en Ligne :

Le code en ligne n'a qu'une `accent grave` autour.

Les blocs de code ont trois accents graves autour. `CODE`. Après le premier accent, ajoutez le langage de votre choix. Regardez ces exemples ci-dessous :

```javascript
var s = 'Coloration de syntaxe JavaScript';
alert(s);
```

```python
s = "Coloration de syntaxe Python"
print s
```

```
Aucun langage indiqué, donc pas de coloration de syntaxe.
Mais ajoutons une <b>balise</b>.
```

## Tableaux

Vous pouvez ajouter des tableaux à vos articles de blog comme ceci.

```markdown
Les deux-points peuvent être utilisés pour aligner les colonnes.

| Tableaux      |      Sont       |  Cool |
| ------------- | :-------------: | ----: |
| col 3 est     | aligné à droite | $1600 |
| col 2 est     |     centré      |   $12 |
| rayures zèbre |   sont nettes   |    $1 |

Il doit y avoir au moins 3 tirets séparant chaque cellule d'en-tête.
Les pipes externes (|) sont optionnels, et vous n'avez pas besoin de faire
que le Markdown brut s'aligne joliment. Vous pouvez aussi utiliser du Markdown en ligne.

| Markdown | Moins   | Joli     |
| -------- | ------- | -------- |
| _Encore_ | `rendu` | **bien** |
| 1        | 2       | 3        |
```

## Citations

Ajoutez une citation en utilisant la syntaxe suivante.

```markdown
> Les citations sont très utiles dans les emails pour émuler le texte de réponse.
> Cette ligne fait partie de la même citation.

Rupture de citation.

> Ceci est une très longue ligne qui sera encore correctement citée quand elle se wrap. Oh garçon, continuons à écrire pour nous assurer que ceci soit assez long pour se wrapper pour tout le monde. Oh, vous pouvez _mettre_ **Markdown** dans une citation.
```

> Les citations sont très utiles dans les emails pour émuler le texte de réponse.
> Cette ligne fait partie de la même citation.

Rupture de citation.

> Ceci est une très longue ligne qui sera encore correctement citée quand elle se wrap. Oh garçon, continuons à écrire pour nous assurer que ceci soit assez long pour se wrapper pour tout le monde. Oh, vous pouvez _mettre_ **Markdown** dans une citation.

## HTML en Ligne

Vous pourriez utiliser du HTML brut dans votre Markdown. Mais comme ceci est MDX, vous ne devriez pas en avoir besoin. Maintenant vous pouvez simplement créer des composants et les importer.

```html
<dl>
  <dt>Liste de définition</dt>
  <dd>Est quelque chose que les gens utilisent parfois.</dd>

  <dt>Markdown dans HTML</dt>
  <dd>
    Ne fonctionne **pas très** bien. Utilisez les balises HTML
    <em>tags</em>.
  </dd>
</dl>
```

<dl>
  <dt>Liste de définition</dt>
  <dd>Est quelque chose que les gens utilisent parfois.</dd>

  <dt>Markdown dans HTML</dt>
  <dd>Ne fonctionne **pas très** bien. Utilisez les balises HTML <em>tags</em>.</dd>
</dl>

## Sauts de ligne

Ma recommandation de base pour apprendre comment fonctionnent les sauts de ligne est d'expérimenter et découvrir -- appuyez sur **Enter** une fois (c'est-à-dire, insérez une nouvelle ligne), puis appuyez deux fois (c'est-à-dire, insérez deux nouvelles lignes), voyez ce qui se passe. Vous apprendrez bientôt à obtenir ce que vous voulez. "Markdown Toggle" est votre ami.

```
Voici une ligne pour que nous commencions.

Cette ligne est séparée de celle du dessus par deux nouvelles lignes, donc ce sera un *paragraphe séparé*.

Cette ligne est aussi un paragraphe séparé, mais...
Cette ligne n'est séparée que par une seule nouvelle ligne, donc c'est une ligne séparée dans le *même paragraphe*.
```
