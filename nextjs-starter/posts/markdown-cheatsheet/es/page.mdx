## Código y Resaltado de Sintaxis (con PrismJS)

Usar PrismJS con Next.js te da la capacidad de compartir y resaltar fragmentos de código.

```
El código en línea tiene solo `una comilla` alrededor.
```

Ejemplo de Código en Línea:

El código en línea tiene solo `una comilla` alrededor.

Los bloques de código tienen tres comillas alrededor. `CÓDIGO`. Después de la primera comilla agrega el lenguaje de tu elección. Mira estos ejemplos abajo:

```javascript
var s = 'Resaltado de sintaxis JavaScript';
alert(s);
```

```python
s = "Resaltado de sintaxis Python"
print s
```

```
No se indica lenguaje, así que no hay resaltado de sintaxis.
Pero agreguemos una <b>etiqueta</b>.
```

## Tablas

Puedes agregar tablas a tus artículos de blog así.

```markdown
Los dos puntos se pueden usar para alinear columnas.

| Tablas         |          Son          | Geniales |
| -------------- | :-------------------: | -------: |
| col 3 es       | alineada a la derecha |    $1600 |
| col 2 es       |       centrada        |      $12 |
| rayas de cebra |     son ordenadas     |       $1 |

Debe haber al menos 3 guiones separando cada celda de encabezado.
Los pipes externos (|) son opcionales, y no necesitas hacer que el
Markdown crudo se vea bonito. También puedes usar Markdown en línea.

| Markdown | Menos       | Bonito   |
| -------- | ----------- | -------- |
| _Aún_    | `renderiza` | **bien** |
| 1        | 2           | 3        |
```

## HTML en Línea

Podrías usar HTML crudo en tu Markdown. Pero como esto es MDX no deberías necesitarlo. Ahora puedes simplemente crear componentes e importarlos.

```html
<dl>
  <dt>Lista de definición</dt>
  <dd>Es algo que la gente usa a veces.</dd>

  <dt>Markdown en HTML</dt>
  <dd>No funciona **muy** bien. Usa etiquetas HTML <em>tags</em>.</dd>
</dl>
```

<dl>
  <dt>Lista de definición</dt>
  <dd>Es algo que la gente usa a veces.</dd>

  <dt>Markdown en HTML</dt>
  <dd>No funciona **muy** bien. Usa etiquetas HTML <em>tags</em>.</dd>
</dl>

## Saltos de línea

Mi recomendación básica para aprender cómo funcionan los saltos de línea es experimentar y descubrir -- presiona **Enter** una vez (es decir, inserta una nueva línea), luego presiónalo dos veces (es decir, inserta dos nuevas líneas), mira qué pasa. Pronto aprenderás a obtener lo que quieres. "Markdown Toggle" es tu amigo.

```
Aquí hay una línea para que empecemos.

Esta línea está separada de la de arriba por dos nuevas líneas, así que será un *párrafo separado*.

Esta línea también es un párrafo separado, pero...
Esta línea solo está separada por una nueva línea, así que es una línea separada en el *mismo párrafo*.
```
